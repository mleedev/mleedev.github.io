# Matthew Lee - Portfolio Website

This repository contains the code for my personal portfolio website, showcasing my projects, skills, and experience as a software engineer.

## Overview

This site is built with HTML, CSS, and JavaScript, highlighting my front-end development skills while presenting my professional background and projects in a clean, accessible format.

## Features

- Responsive design that works across devices
- Project showcase with descriptions and links
- Professional experience timeline
- Skills and technology proficiencies
- Contact information and links to professional profiles

## Running locally

To run this site locally:

1. Clone the repository
2. Install dependencies with `npm install`
3. Start the development server with `npm run dev`
4. Open the local server URL (usually `http://localhost:5173`) in your browser

## Technologies Used

- HTML5
- CSS3
- TailwindCSS
- Vite
- JavaScript (ES Modules)
- PostCSS
- Autoprefixer
- Feather Icons
